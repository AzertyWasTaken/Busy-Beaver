# Sequential Subtitution System

## Composition

- A semi infinite string.
- An ordered list of production rules with an input and an output.

### Program Format

- Each rule is separated by a `_`.
- The input and output must be separated by a `>`.

## Execution

- The string starts with the first cell set to one and other cells to zero.
- You create an ordered list of pattern-and-replacement pairs (pattern → replacement).

## Functions

BBSS(n) where n is the number of input and output cells. Each input must have at least one cell. The initial string is `0`.
