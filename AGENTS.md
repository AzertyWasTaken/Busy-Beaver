# AGENTS

These rules apply to all code and documentation in this repository.

1. Preserve all existing behavior and functionality.
2. Do not change public APIs, exported names, function signatures, data formats, or externally observable behavior.
3. Remove unnecessary complexity, duplication, dead code, redundant logic, and misleading or poor naming.
4. Improve naming where it makes the code clearer, but do not rename public APIs unless absolutely necessary.
5. Follow modern JavaScript best practices when they improve readability or maintainability without changing behavior.
6. Improve existing comments when they are unclear, inaccurate, outdated, or misleading.
7. Do not add new comments unless absolutely necessary.
8. Do not introduce unnecessary abstractions, helper functions, dependencies, or architectural changes.
9. Do not make unrelated changes.
10. Keep the changes focused and minimal.
11. Keep documentation up to date: update `results.md` when results change, `search.md` when deciders change, and `stats.md` when code is added or moved.
